# Sécurité

Une faille se signale en privé, par un avis de sécurité GitHub : <https://github.com/Remiverhaeghe/cursus/security/advisories/new>. Merci de ne pas ouvrir d'issue publique.

Indique la version ou le commit concerné, les étapes pour reproduire et l'impact. Je réponds sous sept jours.

Cursus ne contient que des données fictives, mais une faille d'accès entre profils (un tuteur qui voit les apprentis d'un autre, par exemple) est prise au sérieux comme sur une vraie application.
